# SigmaOS ActiveAndroid

This repository is currently a minimal `no_std` component identity scaffold. Its library exposes a `Component` named `SigmaOS-activeandroid`.

No Android activity lifecycle, application framework, security service, or server functionality is implemented in the current source. The repository name does not establish compatibility with the upstream ActiveAndroid library.

## Build

```sh
cargo check --lib
```
